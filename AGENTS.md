# AGENTS

- Public site absolute URLs (canonical, OG, JSON-LD) come from `src/lib/site.ts`; never hardcode a domain in pages.
- Public blog and article pages read published posts from the `blog_posts` table via `src/hooks/usePublishedPosts.ts` (same source as admin); `src/data/blogContent.ts` is only a fallback when the table has no published post.
- `public/sitemap.xml` is generated by `scripts/generate-sitemap.ts` with permanent routes only; DB-driven articles are not listed so the file never goes stale.
- Acquisition-system content (steps, service roles, team roles) lives in `src/data/systemContent.ts` so copy changes never touch components.
- Visual system rules live in `DESIGN.md`; read it before changing public UI.
